# Phonetics asset reproduction

`scripts/build-phonetics-assets.py` extracts and compresses source data; it is not a standalone clean-checkout build. The generated dictionary/model files are committed under `src/browser/phonetics/assets/`.

## Python inputs

Use Python 3.11 with these exact packages available in the repository `.venv`:

- `python-mecab-ko-dic==2.1.1.post2`
- `nltk==3.10.3`
- `g2p-en==2.1.0`
- `pykakasi==2.3.0`
- `numpy==2.4.6`

The build expects the Korean dictionary at `.venv/Lib/site-packages/mecab_ko_dic/dictionary/`, the g2p-en `checkpoint20.npz` and pykakasi package in that same environment, and `cmudict.zip` at `_internal/nltk_data/corpora/cmudict.zip`. The CMU corpus is cmudict.0.7a; its notice is in `NOTICE.md`. Install or source these inputs before running the script:

```powershell
.venv\Scripts\python.exe web\scripts\build-phonetics-assets.py
```

It writes the compressed Korean dictionary, `g2pk/cmudict.json`, the g2p-en checkpoint binary, and the pykakasi tables. The Korean G2P JavaScript rules and table files are vendored from `g2pk-nodejs@0.1.0`; they are not generated by this script.

## MeCab WebAssembly core

`mecab/libmecab.js` and `mecab/libmecab.wasm` are prebuilt files from `mecab-wasm@1.0.3`, committed separately from the asset script. To refresh those files, fetch that exact npm package (`npm pack mecab-wasm@1.0.3`) and copy its matching core files into `mecab/`. The package's Emscripten build is upstream of this repository; the asset script does not recompile it. Keep `mecab/LICENSE.mecab` and `mecab/LICENSE.mecab-ipadict` with the core. The Korean dictionary is separately generated from `python-mecab-ko-dic==2.1.1.post2`; no Japanese MeCab dictionary is included.

## Japanese table source

The bundled Kanwa, Itaiji, and Hepburn tables are derived from `pykakasi==2.3.0` (GPL-3.0-or-later). `scripts/build-phonetics-assets.py` shows the exact exported tables. The package license and authors are kept beside `pykakasi.json.gzbin`.
